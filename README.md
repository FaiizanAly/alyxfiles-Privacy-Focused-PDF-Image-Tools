# 📁 alyxfiles

A simple PDF and image utility website that lets you manage your files directly in your browser — no uploads, no accounts, no fuss.

---

## ✨ Features

### PDF Tools
- 📄 Merge PDF
- ✂️ Split PDF
- 🗑️ Delete PDF Pages
- 🔄 Organize & Rotate PDF
- 📦 Compress PDF
- 🖼️ PDF to Image
- 📑 Image to PDF

### Image Tools
- 🗜️ Compress Image
- 📐 Resize Image
- ✂️ Crop Image
- 🔄 Convert Image
- ✨ Enhance Image
- 📷 Scan / Document Enhance

---

## 🔒 Privacy

Your files never leave your device.

- All processing happens **locally in your browser**
- Files are **not uploaded** to any server for processing
- **No account** required
- alyxfiles does **not store** your files
- Temporary processing data is cleared when it is no longer needed

---

## 🚀 How to Use

1. Open the website
2. Choose the tool you need
3. Add your PDF or image
4. Process the file
5. Download the result

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript

A fully **client-side, static website** — no backend, no database, no server-side file processing.
